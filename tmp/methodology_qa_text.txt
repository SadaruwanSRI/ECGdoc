5 Methodology

This chapter explains the final system saved and used by the application. The installed model
is a one-lead MLII beat classifier. It does not use two ECG leads, does not retrain during live
use, and does not make an arrhythmia decision directly from the autoencoder threshold. The
final decision is made by two supervised Extra Trees models. Both receive the same 242-value
feature vector.


5.1 Architecture in one sentence
  For each detected MLII heartbeat, the system takes a 512-sample window aligned to the R
peak, builds waveform, rhythm, and normal-reconstruction features, sends those features to a
binary abnormality gate, and sends only gated abnormal beats to a five-class subtype classifier.

5.4.5 Normal-reference data and checkpoint
   The autoencoder checkpoint was developed from complete recordings of all 18 subjects in
the MIT–BIH Normal Sinus Rhythm Database. Fifteen subjects supply 288,673 fitting windows
and three different subjects supply 57,177 validation windows. The selected NSRDB header
channel is ECG1. The database does not document this channel as anatomical Lead II, so the
report treats it as a normal ECG reference channel rather than renaming it MLII [6].
   The final checkpoint uses Adam, learning rate 0.001, batch size 256, and two epochs.
Validation MSE changed from 0.061195 after epoch 1 to the best saved value, 0.061193, after
epoch 2. The autoencoder artifact also stores a normal-residual threshold of 0.158893, but the
final hierarchy does not use that threshold as the final arrhythmia rule.

5.6 How an Extra Trees model learns
   Both supervised stages use the same type of architecture: an ensemble of extremely ran-
domised decision trees. A tree asks a sequence of questions of the form “is feature 𝑧 𝑗 ≤ 𝜏?” The
answer sends a beat to a left or right child node. Randomly chosen candidate features and split
values make different trees learn different partitions; among the candidate splits at a node, the
algorithm chooses the one that best separates the weighted training labels [32].

5.8 Abnormal-subtype classifier
   The second supervised model is used only after the binary gate marks a beat as abnormal. It
is fitted only on supported abnormal classes 1–5, not on N and not on unsupported MIT–BIH
symbols. The selected subtype model is an Extra Trees classifier with:
    • 260 trees;
    • entropy split criterion;
    • fully grown trees;
    • minimum leaf size of one sample;
    • one-third feature sampling at each split;
    • record/class weighting with record-power 𝛼 = 0.25.
5 Methodology                                                                               48


   This model’s target is one of five supported abnormal labels. It has no normal output.
Its three candidate structures were fitted on 22,844 supported abnormal candidate beats and
compared on 5,651 supported abnormal validation beats. The chosen structure was refitted
on 28,758 supported abnormal development beats. The feature-sampling fraction 0.33 means
roughly 80 of the 242 feature positions are proposed at a node. Entropy now sums over five
classes, so a node with an exactly even five-class mixture would have 𝐻 = log2 5 ≈ 2.322
bits. A split lowers this entropy when its children become more concentrated in particular
arrhythmia groups.
   For an abnormal beat, the subtype classifier returns scores over the five supported abnormal
outputs: PVC, PAC, LBBB, RBBB, and AFib. The final class score 𝑞𝑖𝑐 is Equation 5.22 with
𝐵 = 260 and only these five training classes. The final subtype is
     𝑦b𝑖 = arg max 𝑞𝑖𝑐 .                                                                 (5.26)
                𝑐∈{1,...,5}

Thus the subtype forest does not learn a second normal-versus-abnormal decision. It re-
solves the abnormal branch by taking the largest of its five scores. Candidate subtype
forests were selected by validation macro F1, which gives each of the five classes equal
influence in the selection score, then by validation accuracy. The final saved bundle sets
reject_low_confidence=False. Therefore the evaluated and installed final pipeline
do not add a post-hoc “Unclassified abnormal” rejection step; every gated abnormal beat
receives the subtype with the largest subtype probability.
   The displayed subtype confidence is conditional on the abnormal branch. It is an ensemble
score, not a calibrated probability of disease. Unsupported abnormalities can receive an
incorrect supported subtype.


5.9 Final decision logic
  The complete prediction rule is:
   1. Validate that the input is a 512-sample MLII beat window and that 15 RR features are
      available.
   2. Reconstruct the same window with the frozen autoencoder.
   3. Build the 242-value vector from MLII shape, RR timing, and four autoencoder residual
      summaries.
   4. Estimate 𝑝𝑖 = 𝑃 (abnormal | 𝑥𝑖 ) using the 240-tree binary detector.
   5. If 𝑝𝑖 ≤ 0.5708333, output N with confidence 1 − 𝑝𝑖 .
   6. If 𝑝𝑖 > 0.5708333, run the 260-tree subtype model and output the highest-probability
      supported subtype.
  This is the same hierarchy used in the final temporal-holdout evaluation. The model does
not use test labels while predicting. The labels are used only after prediction to compute
accuracy, F1, confusion matrices, and subject-clustered uncertainty.
