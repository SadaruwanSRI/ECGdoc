\section{Saved success checks}

The JSON artifact records three Boolean checks. Pooled whole-system accuracy
above 90\% is true. A whole-system subject-cluster lower 95\% bound above 90\%
is true. Interval width at most three percentage points is true for the corrected rerun.

\section{Safety statement}

The installed artifact is a research model. The final experiment uses patient
overlap, one MITDB lead, and annotated R-peak locations during evaluation. It
is not a certified medical device and must not be used to diagnose or treat a
patient.

\section{Verification and historical record}
The original August results remain in
\nolinkurl{experiments/final_temporal_holdout.json}.
The corrected run saves all test predictions in
\nolinkurl{experiments/corrected_test_predictions.npz}, and independent checks
are recorded in \nolinkurl{experiments/final_verification.json}.
The INCART result and predictions are
\nolinkurl{experiments/corrected_external_incart.json} and
\nolinkurl{experiments/corrected_external_predictions.npz}.
Model SHA-256 digests link the evaluated bundle to its deployed copy.

From the repository root, use the backend Python environment to run
\nolinkurl{Final_Report_Research/tools/verify_final_results.py}.
The corrected training entry point is
\nolinkurl{Final_Report_Research/tools/final_temporal_holdout.py};
it uses \nolinkurl{tools/corrected_dataset.py} and the shared
\nolinkurl{backend/app/ml/beat_preparation.py}.
The NSRDB checkpoint is frozen and is not retrained by this entry point.
Running training again replaces the corrected artifacts, so preserve the
current experiment directory before any future research change.
