\section{Recorded evaluation targets}

The saved JSON file records that all three whole-system targets were met:
pooled accuracy above 90\%, a lower 95\% confidence bound above 90\%, and
an interval width of at most three percentage points. These checks describe
the retrospective evaluation; they do not establish independent validation.

\section{Safety statement}

The installed artifact is a research model. The final experiment uses patient
overlap, one MITDB lead, and annotated R-peak locations during evaluation. It
is not a certified medical device and must not be used to diagnose or treat a
patient.

\section{Verification and historical record}
The following files retain the results and verification record:
\begin{itemize}
\item Original August results:\newline
\nolinkurl{experiments/final_temporal_holdout.json}.
\item Revised temporal predictions:\newline
\nolinkurl{experiments/corrected_test_predictions.npz}.
\item Independent verification:\newline
\nolinkurl{experiments/final_verification.json}.
\item External INCART results:\newline
\nolinkurl{experiments/corrected_external_incart.json}.
\item External INCART predictions:\newline
\nolinkurl{experiments/corrected_external_predictions.npz}.
\end{itemize}
Model SHA-256 digests link the evaluated bundle to its deployed copy.

Use the backend Python environment to run the verification script at
\nolinkurl{tools/verify_final_results.py} within the report directory.
The supervised training entry point is
\nolinkurl{tools/final_temporal_holdout.py}.
It uses \nolinkurl{tools/corrected_dataset.py} and the shared preparation
module at \nolinkurl{backend/app/ml/beat_preparation.py}.
The NSRDB checkpoint is frozen and is not retrained by this entry point.
Running training again replaces the corrected artifacts, so preserve the
current experiment directory before any future research change.
